# TamerCAD: Phase 3 Deepening - Edge Selection & Fillet/Chamfer Manipulators

This plan extends the hierarchical selection system to support **Edges** and introduces interactive 3D manipulators for **Fillet** and **Chamfer** operations. This allows users to select specific edges of a 3D solid and dynamically adjust their rounding or beveling.

## User Review Required

> [!IMPORTANT]
> **Edge Picking Sensitivity**: Picking an edge requires higher precision than a face. We will implement a proximity threshold (e.g., 20 pixels on screen).
> **Feature Association**: Edges of a solid generated by an `ExtrudeFeature` will initially be associated with that feature. Applying a Fillet/Chamfer will create a *new* feature in the history tree that modifies those specific edges.

## Proposed Changes

### 1. Edge Selection & Metadata
- **[MODIFY] core/geometry/Line.kt**:
    - Add `var parentFeatureId: String? = null` to track which feature created/owns this edge.
- **[MODIFY] ui/CADViewModel.kt**:
    - Update `pick3DEntity` to include Edge detection.
    - **Priority**: Sketch Geoms > Edge > Face > Body.
    - If a Body is selected, the second tap prefers an Edge if the stylus is close enough; otherwise, it selects a Face.

### 2. Fillet and Chamfer Features
- **[NEW] core/features/FilletFeature.kt**:
    - Targets a list of edge IDs.
    - Property: `var radius: Double`.
    - `evaluate()`: Modifies the `Solid3D` geometry to represent rounded edges (B-Rep approximation).
- **[NEW] core/features/ChamferFeature.kt**:
    - Targets a list of edge IDs.
    - Property: `var distance: Double`.
    - `evaluate()`: Modifies the `Solid3D` geometry to represent beveled edges.

### 3. Edge-Specific 3D Manipulators
- **[MODIFY] ui/viewport/Manipulator3D.kt**:
    - Add `drawEdgeManipulator`: Draws a handle (handle sphere or offset arrow) at the midpoint of the selected edge.
    - Implement `hitTest` for this new handle.
- **[MODIFY] ui/components/CADCanvas.kt**:
    - Detect when an `EDGE` is selected and render the appropriate manipulator.

### 4. Direct Modeling for Edges
- **[MODIFY] ui/CADViewModel.kt**:
    - In `onSketchDrag`, handle `activeManipulatorAxis == "EDGE_OFFSET"`.
    - Project drag amount to update `FilletFeature.radius` or `ChamferFeature.distance`.
    - Trigger live geometry rebuild.

## Roadmap

1.  **Selection Update**: Implement Edge picking and highlight.
2.  **Feature Models**: Create `FilletFeature` and `ChamferFeature` classes.
3.  **Manipulator**: Render and hit-test edge handles.
4.  **Interaction**: Connect dragging to Fillet/Chamfer parameters.

## Verification Plan

### Automated Tests
- Test Ray-Line proximity math (Edge picking).
- Verify `FilletFeature` correctly updates its internal state.

### Manual Verification
- **Edge Selection**: Tap an edge of a cube; verify only that line highlights.
- **Fillet Drag**: Drag the handle on the edge; verify the "Fillet" label updates (and ideally the geometry starts to curve).
- **Contextual Menu**: Verify "Fillet" and "Chamfer" buttons appear in the alt bar when an edge is selected.
