# TamerCAD

TamerCAD is a professional Android CAD application designed for tablets and stylus input.

The long-term goal of this project is to provide a lightweight but powerful CAD environment inspired by Shapr3D while remaining optimized for Android devices.

## Main Goals

- Stylus-first workflow
- Parametric sketching
- Constraint system
- Solid modeling
- Real-time rendering
- STEP/STL export
- Modern Material 3 UI
- Modular architecture
- MVVM + Clean Architecture
